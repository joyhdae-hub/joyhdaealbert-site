# joyhdaealbert.com

Personal professional site for Joyhdae Albert. A static site: plain HTML, CSS, and JavaScript, deployed on Netlify.

**Why no framework?** The site is a handful of pages whose content is JSON. A ~400-line dependency-free Node script (`scripts/build.mjs`) turns `/data` into HTML, so content is in the page source (good for search and no-JavaScript visitors), nothing needs installing, and there is no framework to keep updated. The only client-side JavaScript is small and optional: nav highlighting, count-up, forms, and the demo.

## Run locally

Requires Node 18 or newer.

```bash
npm start
```

This builds into `dist/` and serves it at http://localhost:8080. To only build: `npm run build`.

## Deploy on Netlify

1. In Netlify, choose **Add new site, Import an existing project** and pick this repository.
2. Build settings (also set in `netlify.toml`, so they are picked up automatically):
   - **Build command:** `npm run build`
   - **Publish directory:** `dist`
3. Production branch: `main`. Add the custom domain `joyhdaealbert.com` under Domain management.
4. **Forms:** Netlify Forms is detected from the built HTML on each deploy. Check Site configuration, Forms, that "Form detection" is enabled. Submissions appear under Forms (`contact` and `template-request`). Turn on email notifications there to be told about new ones.

Headers (security and caching) are in `netlify.toml`. 404s use `404.html` automatically.

## Templates

Three free templates are generated by a script (Python 3 with `openpyxl` and `python-docx`) and committed to `downloads/`:

```bash
pip install -r scripts/requirements.txt
npm run generate-templates
```

This rewrites `downloads/vendor-contract-tracker.xlsx`, `downloads/event-run-of-show.docx`, and `downloads/office-move-checklist.docx`. Each carries the license line in its footer and has author, company, and last-modified-by metadata blanked. Edit the content in `scripts/generate_templates.py`; bump `version` and `updatedAt` in `data/templates.json` when you regenerate.

Check the files before publishing:

```bash
npm run check-templates
```

It scans every file in `downloads/` for terms in `config/blocklist.txt` (one per line; starts empty) and for author, company, and last-modified-by metadata, and prints PASS or FAIL per file (exit code 1 on any failure). Note: for PDFs it reads metadata and uncompressed text only.

## Resume

`/resume/` is built from the same data and has a print stylesheet that fits one US Letter page. "Save as PDF" opens the print dialog; choose "Save as PDF" as the destination, with margins set to Default and background graphics on.
